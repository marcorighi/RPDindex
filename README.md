# RPDindex

RPDindex provides a reference implementation of the **RPD (Realistic Performance Determination) index family**, a set of synthetic indices for assessing directional changes in normalized sequential data. The implementation accompanies the manuscript submitted to *Scientific Reports*:

> Marco Righi, Cristina Dolciotti, Davide Moroni, and Paolo Bongioanni, *Synthetic RPD Index Proposal for Analyzing Directional Changes in Normalized Data*.

The software implementation in this repository was developed by Marco Righi.

The software DOI will be added after Zenodo archiving:

> **Software DOI:** `10.5281/zenodo.20313684`

The associated manuscript is currently under review and does not yet have an article DOI.

## Purpose

The RPD indices are designed to quantify whether a data series shows an overall tendency toward improvement, degradation, or neutrality. The expected input is a finite ordered sequence of numerical values. In the experiments associated with the manuscript, the values are normalized in the range `[0, 1]`, and larger values are interpreted as better results.

The index values are in the interval `[-1, 1]`:

- `1` indicates a consistently improving trend;
- `0` indicates a neutral or balanced trend;
- `-1` indicates a consistently degrading trend.

## Implemented indices

The repository includes six indices, divided into local and global families.

### Local indices

- `RPDlep(elements)`: local ex-post index; adjacent comparisons with equal global weighting.
- `RPDlea(elements)`: local ex-ante index; adjacent comparisons with stronger influence from early observations.
- `RPDlepr(elements)`: local ex-post reverse index; adjacent comparisons with stronger influence from late observations.

### Global indices

- `RPDgep(elements)`: global ex-post index; all pairwise comparisons with equal global weighting.
- `RPDgea(elements)`: global ex-ante index; progressive global comparisons with stronger influence from early observations.
- `RPDgepr(elements)`: global ex-post reverse index; progressive global comparisons with stronger influence from late observations.

The comparison rule is implemented in:

```python
def isAworstThanB(A, B):
    ...
```

By default, `A < B` is interpreted as improvement from `A` to `B`. If equal values are compared, the comparison is treated as neutral.

The CSV files generated by the MATLAB scripts contain three columns without a header:

```text

```

where `x` is the task/sample coordinate, `result` is the noisy generated value, and `trend` is the corresponding noiseless model value.

## Requirements

### Python

The RPD index implementation was written for Python 3.11 and uses only the Python standard library.

No external Python package is required for `computeindex.py`.

### MATLAB

The synthetic data generation scripts use MATLAB functions such as `linspace`, `rng`, `binornd`, and `writematrix`. The use of `binornd` requires the Statistics and Machine Learning Toolbox.

## Basic usage

Place `computeindex.py` in your working directory or import it from the repository.

```python
from computeindex import RPDlep, RPDlea, RPDlepr, RPDgep, RPDgea, RPDgepr

values = [0.10, 0.25, 0.40, 0.55, 0.80]

print("RPDlep :", RPDlep(values))
print("RPDlea :", RPDlea(values))
print("RPDlepr:", RPDlepr(values))
print("RPDgep :", RPDgep(values))
print("RPDgea :", RPDgea(values))
print("RPDgepr:", RPDgepr(values))
```

Expected interpretation: because the sequence is monotonically increasing, the indices should return values close to `1` or exactly `1`, depending on the index and the absence of neutral comparisons.

## Example with a CSV file

The generated CSV files do not include a header. The second column is the noisy result series, and the third column is the underlying trend series.

```python
import csv
from computeindex import RPDlep, RPDgep

filename = "example.csv"

result = []
trend = []

with open(filename, newline="") as f:
    reader = csv.reader(f)
    for row in reader:
        result.append(float(row[1]))
        trend.append(float(row[2]))

print("RPDlep on noisy result:", RPDlep(result))
print("RPDgep on noisy result:", RPDgep(result))
print("RPDlep on trend:", RPDlep(trend))
print("RPDgep on trend:", RPDgep(trend))
```

## Reproducing synthetic data

Run one of the MATLAB scripts from MATLAB or GNU Octave-compatible environments where the required functions are available:

```matlab
logistic_degrade_0
logistic_degrade_1
logistic_degrade_2
```

The scripts generate synthetic normalized data series from logistic models, optionally combined with sinusoidal components and binomial noise. Output files are written in the `01_csv/` directory.

Before running the scripts, create the output directory if it is not already present:

```matlab
mkdir('01_csv')
```
